# 树莓派AI助手完整项目指南

## 项目概览

本项目将Qwen3-0.6B大语言模型部署到树莓派5上，打造一个具备语音交互能力的贴身AI助手。

### 核心组件
1. **数据集**: FineWeb-Edu (教育质量高的网络文本数据集)
2. **基础模型**: Qwen3-0.6B (阿里巴巴开源的6亿参数模型)
3. **微调框架**: Unsloth (高效的LLM微调工具)
4. **语音识别**: Faster-Whisper (OpenAI Whisper的优化版本)
5. **语音合成**: Piper TTS (轻量级文字转语音引擎)
6. **部署平台**: 树莓派5 (8GB RAM版本)

---

## 第一部分：FineWeb-Edu 数据集调查

### 数据集简介
FineWeb-Edu是由Hugging Face团队创建的高质量教育文本数据集，包含1.3万亿tokens。

### 核心特点
- **来源**: 从15万亿token的FineWeb数据集筛选而来
- **筛选方法**: 使用Llama-3-70B-Instruct标注教育质量（0-5分），保留3分以上内容
- **性能提升**: 在MMLU、ARC等知识密集型基准测试中显著优于其他开源数据集
- **数据规模**: 约5.4TB（压缩后约1.3TB tokens）

### 获取方式
```python
from datasets import load_dataset

# 加载完整数据集（非常大，需要大量存储空间）
dataset = load_dataset("HuggingFaceFW/fineweb-edu", split="train", streaming=True)

# 或加载采样版本用于测试
dataset = load_dataset("HuggingFaceFW/fineweb-edu", 
                      name="sample-10BT",  # 10B tokens样本
                      split="train")
```

## 第二部分：大模型微调Python框架调查

### 主流框架对比

#### 1. Unsloth ⭐推荐用于本项目
**优势**:
- 速度快2-5倍，内存使用减少80%
- 无精度损失
- 支持单GPU训练
- 非常适合消费级GPU（如24GB显存）

**适用场景**: 资源受限环境、快速实验

**安装**:
```bash
pip install unsloth
```

#### 2. Axolotl
**优势**:
- 易用性强，配置简单
- 支持多GPU训练
- 社区活跃，模型支持广泛

**适用场景**: 多GPU训练、企业级应用

#### 3. TorchTune (PyTorch官方)
**优势**:
- 纯PyTorch实现，无额外抽象
- 与PyTorch生态无缝集成
- 支持多节点训练

**适用场景**: 需要深度定制、大规模训练

#### 4. LLaMA-Factory
**优势**:
- 支持100+模型
- 提供Web UI界面
- 功能全面（SFT、DPO、PPO等）

**适用场景**: 需要图形界面、多种训练方法

### 推荐选择
**本项目使用Unsloth**，原因：
- 内存效率高，适合24GB显存GPU
- 微调速度快
- 代码简洁，易于理解
- 直接支持Qwen3系列模型

## 第三部分：语音转文字与文字转语音模型调查

### 语音转文字 (STT/ASR)

#### 推荐方案：Faster-Whisper
**选择理由**:
- OpenAI Whisper的优化版本
- 速度提升4倍，内存使用减少
- 可在树莓派5上运行
- 准确率与原版Whisper相当

**性能指标**:
- WER (词错误率): 通常<5%（英语）
- 延迟: 实时因子<1.0（在树莓派5上）
- 支持语言: 99种语言

**替代方案**:
1. **AssemblyAI Universal-2**: 云端服务，准确率最高，但需要网络
2. **Wav2Vec 2.0**: Meta开源，支持无标注数据训练
3. **DeepSpeech**: Mozilla开源，较为轻量

### 文字转语音 (TTS)

#### 推荐方案：Piper TTS
**选择理由**:
- 专为树莓派等边缘设备优化
- CPU推理速度快
- 声音质量自然
- 模型文件小（<100MB）

**性能指标**:
- 延迟: 实时因子约0.5（快于实时）
- 音质: MOS评分4.0+（5分制）
- 支持语言: 40+种语言和方言

**替代方案**:
1. **XTTS-v2**: 语音克隆能力强，但计算需求高
2. **Bark**: 情感表达丰富，但推理慢
3. **Microsoft Edge TTS**: 云端服务，质量高但需要网络
